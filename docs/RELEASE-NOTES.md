# v0.2.0 prototype

- Compact stop overview brings the rehearsal task higher in the desktop workspace.
- Hover and keyboard focus preview a stop; click, Enter and tap open it. A dashed preview and polite announcement keep preview separate from the current scenario.
- Current-stop example questions sit beside the task on desktop and in a native disclosure before choices on mobile.
- Workspace navigation remains available during normal scrolling. Selected disclosure rows and relevant-request labels make state relationships clearer.
- Keyboard preview survives scroll; pointer preview resets and can be deliberately re-engaged. Escape, blur, navigation, cancellation and live preference changes leave a valid state.
- Small-screen Reset and primary controls retain 44-pixel targets. Reduced motion keeps stable geometry and complete feedback.

The confirmation/invalidation model and selective-note implementation are unchanged from the reviewed baseline. Requests and self-recorded evidence remain unverified. No clinic availability is inferred. Browser storage is unencrypted; downloaded exports remain after reset.

Earlier v0.1.0 screenshots and demo recordings are historical views, not current v0.2.0 captures. They were not rerendered or relabelled for this release. No film, narration, hosting or event submission is included. No clinical effectiveness or complete accessibility certification is claimed.
